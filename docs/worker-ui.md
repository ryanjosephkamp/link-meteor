Owned files: `src/ui/workbench.html`, `src/ui/workbench.css`, `src/ui/workbench.js`, this note. No core, background, capture, manifest, Git, or browser-test files were edited by this worker.

The shared workbench page is structured for a narrow side panel and a full tab. It includes collection creation, activation, rename, notes, tags, and deletion; capture scope preview and selected-tab picker; region selection; source-aware occurrence review; filters, sorting, grouping, selection, removal and undo; ordered export columns and downloads for all contracted formats; three clipboard actions; bookmark folder creation; bounded link opening; and per-site hold-key controls. User-provided link text and URLs enter the DOM through `textContent` or text nodes. Clickable links are limited to HTTP(S). The visual design uses packaged CSS and system fonts, with light/dark and reduced-motion variants.

Scope selection requests the optional `tabs` permission from the radio gesture. Multi-tab capture requests the exact HTTP(S) origins in its button gesture, then refreshes tab inventory. If an origin changed while asking for permission, capture stops and asks for another click. A declined origin request proceeds to the background capture report, so denied pages can appear there. Current-page capture sends `tabIds: []` without requesting optional permissions. Bookmark permission and hold-site origin permission are also requested from their respective button or toggle gestures.

Selection is tracked by occurrence ID across redraws. For exports, selected *visible* occurrences take precedence; otherwise the current filtered rows are used. A grouped row is the representative for tabular, text, Markdown, HTML, bookmark, and open actions. JSON retains each row's complete `occurrences` array. The UI states this behavior beside the output controls. Opening deduplicates HTTP(S) URLs, rejects more than 20, and asks for the exact count before sending `links.open`.

Integration followups: The review list renders at most 100 top-level rows per page, with a page range and accessible Previous/Next controls. Selection spans pages; “Select this page” affects only the current page, while an unselected export still uses every filtered row. Search, filters, and sorting return to page one. Unsaved collection and link note/tag drafts survive state redraws. The current site preview refreshes from `tabs.list` and its `targetTabId` on tab and window changes. Native shortcut/context-menu activation errors appear from session storage. Context-menu capture reports appear on initial load and session changes, remain visible until replaced or dismissed, and use a session dismissal marker to avoid resurfacing the same report in another workbench view. The UI avoids duplicate display of an identical report. HTTP(S)-only open and bookmark actions disclose skipped non-web rows.
