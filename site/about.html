Bugs and suggestions

Found something that doesn't work, or have an idea? Open an issue on GitHub. It's the main way to contact the project, and you can follow the reply there.

Report a bug or suggest a feature

For a bug report, include

  • Your Link Meteor version. It's shown on Link Meteor's card in chrome://extensions, and in newer versions under About and help in the extension.
  • Your Chrome version (from chrome://version) and operating system.
  • The steps you took, what you expected, and what happened instead.

Issues are public. Leave out private or work URLs, your collections, notes, screenshots of private pages and anything like a password or token. If you can, reproduce the problem on the practice page and describe that instead.

Before reporting missing links, check limits and coverage. Some parts of pages, such as frames from other sites, can't be read by any extension.

Support

Every Link Meteor feature is free, with no account, ads or paid tier. If it saves you time and you'd like to support its development, you can sponsor Ryan on GitHub. Sponsorship is entirely optional and never unlocks features or changes how the extension works.

How the videos were made

The demo and the install walkthrough were recorded with Link Meteor 0.2.2 in Chrome for Testing, the automated build of Chrome used for this project's tests, on macOS. They use a fresh test profile and only the synthetic content of the practice page: no personal browsing data or real collections.

  • Recorded screens. The install page, Chrome's Extensions and Keyboard shortcuts pages, the practice page, the full view and the side panel's contents appear as they were recorded. The pointer is drawn from the recorded pointer positions. The key caps are an on-screen graphic; the selection was started by the same command the shortcut sends.
  • Selecting on the practice page. The test browser was given site access for the practice page through Chrome's Allow prompts, and the installed extension then ran its own selection script. The drag, highlights, count, card and saved links are all the extension's.
  • Side panel. Its contents are shown at side-panel width next to a still of the page. Chrome's own side-panel frame isn't pictured.
  • Illustrations. Unzipping, Chrome's file picker and pinning from the toolbar are drawn diagrams, marked Illustration in the corner.
  • The spreadsheet. The workbook view is drawn from the file actually downloaded during recording, read with a file reader, not Microsoft Excel.

Chrome for Testing labels the shortcut scope “In Chromium”; everyday Chrome says “In Chrome”. The videos have no sound or music. Captions are part of the picture, and each page also offers a caption track and a transcript.
