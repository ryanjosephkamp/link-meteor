Where things are

On the page
While you select a region, a small bar at the top of the page explains the gesture, matching links light up, and a count follows your pointer. When you let go, a card lists what you selected and where it will be saved.
Side panel
Click the Link Meteor icon in Chrome's toolbar to open the side panel beside the page you're reading. It shows your active collection, capture options and your links. Use the folder button for collections and site settings, and Export at the bottom for copying and downloading.
Full workbench
The expand button in the side panel opens the same workbench in its own tab, with your collections, links and export options side by side, and links shown as anchor text, URL and source columns.

Select a region

Press ⌥ ⇧ L on a Mac or Alt Shift L on Windows and Linux. You can also choose Select a region in the side panel, or right-click the page and choose Link Meteor: select a region. Then drag a rectangle across the links you want.

  • A link is included when any visible part of it overlaps your rectangle, even by a pixel. Links that wrap across several lines count if any line overlaps.
  • Drag toward the edge of the window, or use your scroll wheel while dragging, to scroll the page or a scrolling box. Links you've already passed stay selected.
  • Press Esc at any time to cancel. Nothing is saved until you choose an action.

When you let go, choose one of:

Copy text + URL
Copies two tab-separated columns, anchor text and URL, with a header row, ready to paste into a spreadsheet. Nothing is saved.
Add to collection
Saves the links to the collection named on the card.
Review
Saves them and opens the full workbench.
Add another region
Saves these links, then starts a new selection so you can keep going.

Hold-key drag

On sites where you collect often, you can skip the shortcut. Open the side panel on that site, open collections and site settings, and turn on Hold-key drag on this site. Chrome asks whether Link Meteor may access that one site.

From then on, hold the letter key (Z unless you change it) and drag. Typing in a text box, search field or editor never starts a selection. Turning the setting off stops it on that site. If you remove the site's access in Chrome's settings, Link Meteor turns hold-key drag off there automatically.

Pages, tabs and windows

In the side panel, choose how much to capture, then press the capture button. The button always says exactly what it will do, such as Capture 3 tabs.

This page
Every loaded link on the page you opened Link Meteor from, including links inside open shadow roots and frames from the same site.
Pick tabs
Choose exact tabs from a list of your open tabs, grouped by window.
This window
Every ordinary tab in the current window.
All windows
Every ordinary tab in every normal window of your current Chrome profile.

The first time you choose anything other than This page, Chrome asks whether Link Meteor may see your list of tabs. When you capture, Chrome also asks for access to the sites involved. If you decline, those pages are reported as denied; everything else is still captured. Tabs opened after you start a capture aren't added to it, and one capture can include up to 100 tabs.

The capture report

After a page or tab capture, a report lists every page with its own result. Choose Show only these links to filter the list to that capture.

Captured
The number of links saved from that page, with notes about anything skipped, such as frames from other sites or malformed links.
No links
The page loaded and has no links Link Meteor can read. This is different from being denied access.
Access denied
Link Meteor doesn't have permission for that site. Capture again to be asked, or allow access in Chrome's extension settings.
Unsupported page
Chrome's own pages, the Chrome Web Store and incognito tabs can't be captured.
Capture failed
The tab closed, navigated to a new page mid-capture, or another error happened. The message says which.

What gets saved

Each captured link is a separate occurrence, even when the same URL appears more than once. Every occurrence keeps these fields apart:

Anchor text
The link's visible text, with runs of spaces and line breaks collapsed to single spaces and the ends trimmed. Hidden text inside a link is left out. A link with no visible text has empty anchor text.
Accessible label
The link's ARIA label, or the alt text of images inside it. Kept separate from anchor text.
URL
The full destination the link points to. Web, email (mailto:) and phone (tel:) links are captured; script links such as javascript: are not.
Original href
The link's address exactly as written in the page, which may be relative.
Source page
The address and title of the page it was captured from, plus the frame's address if the link was inside a frame.
Capture time and batch
When it was captured, and an ID shared by everything captured in the same action.
Notes and tags
Yours to add. They are stored separately and never change what was captured.

Link Meteor never visits a link's destination, so it never replaces a label with a page title and never adds authors, dates or DOIs that weren't on the page.

Review and curate

  • Search matches anchor text, URLs, source pages, notes and tags. Press / to jump to the search box.
  • View opens filters for domain, file type (such as pdf) and whether links stay on the source site, plus sorting and grouping. Active options appear as chips you can remove one by one.
  • Group shows one row per unique URL, or per unique URL and anchor text. Grouping is only a view: each group lists every occurrence, label and source page, and switching back shows them all again.
  • Details: open any row to see every saved field and add notes and tags to that occurrence.
  • Select and remove: tick rows, or tick Select page, then remove. Undo puts removed links back in their original positions.

Long collections are shown 100 rows at a time. Selections carry across pages.

Collections

Every capture goes into the active collection. Create collections for different projects, switch between them from the collections list, and use the pencil button to rename a collection or add notes and tags to it. Deleting a collection asks for confirmation and can't be undone.

Collections are saved on your computer by Chrome and survive restarts. They aren't synced to other computers, and there's no import or cloud backup, so export anything you want to keep elsewhere.

Copy and export

What gets exported: every link in the current view, across all pages, unless you've selected some, in which case only the selected links that still match your filters. The export panel always shows the exact count.

Columns: anchor text and URL by default. Add any saved field and change the order; the table copy and the CSV, TSV, Excel and HTML files follow it.

Copy table, URLs or Markdown
Tab-separated columns, one URL per line, or one [anchor text](URL) per line.
Excel (.xlsx)
A real workbook in which every cell is text, so nothing is turned into a formula, number or date.
CSV and TSV
Properly quoted. Cells that look like formulas (starting with =, +, - or @) get a leading apostrophe so spreadsheets import them as text.
Markdown and HTML
Page text is escaped so it displays as text and can't act as markup.
JSON
Every field for every link. In grouped views, each row includes all of its occurrences.
URL list
One URL per line, exactly as captured.

In a grouped view, tables, text and Markdown use each group's first link; JSON keeps every occurrence and source.

Bookmarks and opening links

Save as bookmarks creates a new folder in Chrome's bookmarks, using anchor text as each bookmark's name (or the URL if a link has no text). Chrome asks for bookmark access the first time. Only web links are bookmarked, and Chrome may sync bookmarks to your other devices according to your own browser settings.

Open in tabs opens up to 20 web links at once as background tabs, after you confirm the number. Opening a link visits that site, like clicking it.

Limits and coverage

  • Only links that are loaded in the page can be captured. Link Meteor doesn't scroll infinite feeds, follow pagination, crawl sites or read PDF contents.
  • Frames from other sites and closed shadow roots can't be read; the report says when frames were skipped. Buttons that navigate with scripts but aren't real links aren't captured.
  • Chrome's own pages, the Chrome Web Store and incognito windows are off limits to extensions.
  • One capture can include up to 20,000 links from a page or region and up to 100 tabs. Larger captures are kept up to the limit and marked as partial.
  • Collections use Chrome's local storage for extensions. If a save ever fails because space runs out, your existing collections are left intact and Link Meteor says so.

These are practical limits of the extension, not paid tiers. Every feature is free.

Keyboard

⌥ ⇧ L / Alt Shift L
Start selecting a region on the current page. Change it at chrome://extensions/shortcuts.
Esc
Cancel a selection, close a confirmation, or go back from a panel view.
/
Jump to the search box.
Tab
Every control can be reached and used with the keyboard, with a visible focus outline.
