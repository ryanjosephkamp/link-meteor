Sandbox · Synthetic links only

Practice page

A page built for trying Link Meteor. Every link below is made up: they point to reserved example domains, back to this page, or to doi.org with the 10.5555 test prefix, which matches no real paper. Nothing here tracks you.

Try this

  1. Open the side panel. Click the Link Meteor icon in Chrome's toolbar.
  2. Select a region. Press ⌥ ⇧ L (Mac) or Alt Shift L, then drag across one section below.
  3. Check the count. Each section lists how many links a full drag across it should select. Compare it with the count on the card.
  4. Look closer. Add them to a collection, open a row's details, try Group: Unique URLs, then export.

Don't have the extension yet? See installation, or try the demo on the home page.
