      Online lookups

      Link Meteor works without the internet. These are extras: each is off until you turn it on, and each says exactly what it sends.

      Fills in a paper’s title, authors, date and journal when you click Look up details.

      What it sends, and where

      Page details lookup is off unless you turn it on. When it is on and you click Look up details, Link Meteor sends the paper’s DOI, arXiv ID or PubMed ID, and nothing else, to:

      • Crossref (api.crossref.org) for DOIs
      • DataCite (api.datacite.org) for DOIs Crossref doesn’t have, including arXiv’s
      • NCBI (eutils.ncbi.nlm.nih.gov) for PubMed IDs

      No page address, link text, note or collection name is sent. No cookies are sent or kept.

      Like any website you visit, those services see your IP address and your browser’s version and language.

      What they return (title, authors, date, journal) is saved in this browser with the link.

      Import links

      From a spreadsheet, a list, a PDF, a web page or bookmarks file, pasted text or a bookmark folder. You see what will be added before anything is. Files are read in this browser and never uploaded.

      Or drop a file here: a PDF’s links are read with their page numbers.

      Backup and restore

      One file with every collection, link, note, tag and setting. It is saved to your downloads and goes nowhere else.

      Removing Link Meteor from Chrome deletes everything it saved. A backup file keeps it.

      Last backup: never

      Link Meteor can use more than Chrome's usual 10 MB of local storage, so large collections and a restore's Undo fit. It all stays in this browser.

      Restore this backup?

      Choosing a file changes nothing. Merge or Replace can be undone here afterwards.

      Undo puts back what was here before, as long as nothing has changed since.
